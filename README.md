# Gastronomía de El Salvador

Landing Page interactiva sobre la riqueza culinaria salvadoreña. 

### 🚀 Tecnologías utilizadas:
* HTML5 (Estructura semántica de 6 secciones)
* CSS3 (Diseño responsivo adaptado a 3 tamaños con Flexbox y CSS Grid)
* JavaScript vanilla (Manipulación del DOM, menú hamburguesa y validación avanzada de formulario con expresiones regulares)
